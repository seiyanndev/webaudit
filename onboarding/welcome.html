Let’s set up your API keys

Sitelume audits any website out of the box. Add two free Google keys to unlock its best features. It takes about five minutes, and you only do it once.

1

Google Gemini AI insights

Writes an executive summary and fix steps tailored to each website, in plain business language.

How to get a free Gemini key
  1. Open Google AI Studio → API keys and sign in with your Google account.
  2. Click Create API key. If asked, choose Create API key in new project.
  3. Copy the key and paste it below. No credit card is needed.
2

Google PageSpeed Insights Speed scores

Adds Google’s mobile speed test and real-visitor Core Web Vitals, the numbers clients see on pagespeed.web.dev.

How to get a free PageSpeed key
  1. Open PageSpeed Insights → Get a key and click Get a Key.
  2. Pick or create a Google Cloud project. Google enables the PageSpeed Insights API for you.
  3. Copy the key and paste it below. The free limit is 25,000 tests a day.

Keys are stored only in this browser and sent only to Google. You can change them any time in Settings.
